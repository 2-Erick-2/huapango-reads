# Huapango +reads

Plataforma de lectura digital de **Editorial Huapango**: catálogo estilo Netflix, fichas de libro y un motor de lectura propio. Hecha con **SolidStart**.

- Estado actual y qué es demo: [`docs/ESTADO.md`](docs/ESTADO.md)
- Para agentes de IA y nuevos colaboradores: [`AGENTS.md`](AGENTS.md)
- Plan: [`docs/ROADMAP.md`](docs/ROADMAP.md) · Decisiones: [`docs/decisiones/`](docs/decisiones/)

```bash
nvm use        # Node 24
npm install
npm run dev    # http://localhost:3000
npm run check  # typecheck + lint + tests + build
```
